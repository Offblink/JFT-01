三、第1学时：环境配置详细步骤

3.1 Maven 环境配置

操作1：下载并安装 Maven

  1. 访问 Maven 官网：https://maven.apache.org/download.cgi
  2. 下载 apache-maven-3.9.x-bin.zip
  3. 解压到 D:\apache-maven-3.9.x（路径不要有中文和空格）

操作2：配置环境变量

  1. 右键 此电脑 → 属性 → 高级系统设置 → 环境变量
  2. 新建系统变量：
    • 变量名：MAVEN_HOME
    • 变量值：D:\apache-maven-3.9.x
  3. 编辑 Path 变量，添加：%MAVEN_HOME%\bin
  4. 测试：打开 CMD，输入 mvn -v，显示版本信息即成功
C:\Users\Administrator>mvn -v
Apache Maven 3.9.6 (...)
Maven home: D:\apache-maven-3.9.x
Java version: 1.8.0_391, vendor: Oracle Corporation

操作3：配置阿里云镜像（加速依赖下载）

  1. 打开 D:\apache-maven-3.9.x\conf\settings.xml
  2. 找到 <mirrors> 标签，添加阿里云镜像：

    
        alimaven
        aliyun maven
        https://maven.aliyun.com/repository/public
        central

操作4：IDEA 集成 Maven

  1. 打开 IDEA，点击 File → Settings → Build, Execution, Deployment → Build Tools → Maven
  2. 设置：
    • Maven home directory：D:\apache-maven-3.9.x
    • User settings file：D:\apache-maven-3.9.x\conf\settings.xml
    • Local repository：D:\maven-repository（自定义本地仓库路径）
  3. 点击 Apply → OK

3.2 Git 环境配置

操作1：下载并安装 Git

  1. 访问 Git 官网：https://git-scm.com/download/win
  2. 下载 Git-2.43.x-64-bit.exe
  3. 安装时选择：
    • Select Components：全部勾选
    • Choosing the default editor：选择 Use Visual Studio Code as Git's editor
    • Adjusting your PATH environment：选择 Git from the command line and also from 3rd-party software

操作2：配置 Git 用户名和邮箱

  1. 打开 CMD 或 Git Bash，输入：
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
  1. 验证配置：
git config --list

操作3：IDEA 集成 Git

  1. 打开 IDEA，点击 File → Settings → Version Control → Git
  2. 设置 Path to Git executable：D:\Git\bin\git.exe
  3. 点击 Test，显示版本信息即成功
  4. 点击 Apply → OK

操作4：Git 基本操作演练

  1. 创建本地仓库：
# 打开项目目录
cd D:\mybatis-demo

# 初始化本地仓库
git init

# 查看状态
git status
  1. 添加文件到暂存区、提交到本地仓库：
# 添加所有文件
git add .

# 提交到本地仓库
git commit -m "首次提交：创建 Mybatis 项目"

# 数据库驱动

jdbc.url=jdbc:mysql://localhost:3306/mybatis_db?useSSL=false&serverTimezone=UTC&characterEncoding=utf8

# 数据库密码（修改为你的密码）

常见问题：

六、第4学时：创建实体类、Mapper 接口详细步骤

6.1 创建实体类 User.java

  1. 在 src/main/java 目录下创建包：com.example.entity
  2. 创建 User.java 类
package com.example.entity;

/**
 * 用户实体类
 * 对应数据库表：user
 */
public class User {
    // 字段（对应数据库表的列）
    private Integer id;       // 用户ID
    private String username;  // 用户名
    private String password;  // 密码
    private String email;     // 邮箱

    // 构造方法
    public User() {
    }

    // getter 和 setter 方法（必须有，否则 Mybatis 无法封装数据）
    public Integer getId() {
        return id;
    }

    public void setId(Integer id) {
        this.id = id;
    }

    public String getUsername() {
        return username;
    }

    public void setUsername(String username) {
        this.username = username;
    }

    public String getPassword() {
        return password;
    }

    public void setPassword(String password) {
        this.password = password;
    }

    public String getEmail() {
        return email;
    }

    public void setEmail(String email) {
        this.email = email;
    }

    // toString 方法（方便调试）
    @Override
    public String toString() {
        return "User{" +
                "id=" + id +
                ", username='" + username + '\'' +
                ", password='" + password + '\'' +
                ", email='" + email + '\'' +
                '}';
    }
}
注意事项：
  • 实体类必须有 无参构造方法（Mybatis 反射创建对象需要）
  • 字段名与数据库列名一致（如果不一致，需要使用 ResultMap 映射）
  • 建议使用包装类型（Integer 而不是 int），避免 NULL 值问题

6.2 创建 Mapper 接口 UserMapper.java

  1. 在 src/main/java 目录下创建包：com.example.mapper
  2. 创建 UserMapper.java 接口
package com.example.mapper;

import com.example.entity.User;
import java.util.List;

/**
 * 用户 Mapper 接口
 * 对应 Mapper XML：UserMapper.xml
 */
public interface UserMapper {

    /**
     * 查询所有用户
     * @return 用户列表
     */
    List findAll();

    /**
     * 根据 ID 查询用户
     * @param id 用户ID
     * @return 用户对象
     */
    User findById(Integer id);
}
注意事项：
  • Mapper 接口的方法名必须与 Mapper XML 中的 SQL 语句 id 一致
  • 返回值类型必须与 Mapper XML 中的 resultType 一致
  • 参数类型必须与 Mapper XML 中的 parameterType 一致

七、实验第1-2学时：编写测试类、运行程序、问题排查

7.1 创建测试类 MybatisTest.java

  1. 在 src/test/java 目录下创建包：com.example
  2. 创建 MybatisTest.java 测试类
package com.example;

import com.example.entity.User;
import com.example.mapper.UserMapper;
import org.apache.ibatis.io.Resources;
import org.apache.ibatis.session.SqlSession;
import org.apache.ibatis.session.SqlSessionFactory;
import org.apache.ibatis.session.SqlSessionFactoryBuilder;
import org.junit.Test;

import java.io.IOException;
import java.io.InputStream;
import java.util.List;

/**
 * Mybatis 测试类
 */
public class MybatisTest {

    @Test
    public void testFindAll() throws IOException {
        // 1. 加载配置文件
        InputStream is = Resources.getResourceAsStream("mybatis-config.xml");

        // 2. 创建 SqlSessionFactory
        SqlSessionFactory factory = new SqlSessionFactoryBuilder().build(is);

        // 3. 创建 SqlSession
        SqlSession session = factory.openSession();

        // 4. 获取 Mapper 代理对象
        UserMapper userMapper = session.getMapper(UserMapper.class);

        // 5. 执行查询
        List users = userMapper.findAll();

        // 6. 遍历结果
        for (User user : users) {
            System.out.println(user);
        }

        // 7. 关闭资源
        session.close();
        is.close();
    }
}

7.3 常见问题排查

问题 原因 解决方案
ClassNotFoundException: com.mysql.cj.jdbc.Driver MySQL 驱动依赖未下载 检查 pom.xml，手动下载依赖
SQLException: The server time zone value 时区错误 在 db.properties 中添加 serverTimezone=UTC
BindingException: Invalid bound statement Mapper 接口与 XML 不匹配 检查 namespace、id 是否一致
NullPointerException SqlSession 未开启自动提交 使用 factory.openSession(true) 或手动 commit
