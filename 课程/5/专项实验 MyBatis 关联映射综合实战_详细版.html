二、核心知识点

四种关系在项目中的落点

所有实现都在 com.chapter05 两个 Mapper 与对应 XML 中。

text
com.chapter05.Chapter05EmpMapper
├── one2oneByXml(empno)       # 一对一  XML  嵌套结果
├── one2oneByAnn(empno)       # 一对一  注解  @One 嵌套 select
├── many2oneByXml()           # 多对一  XML  一条 JOIN 查询全部
├── many2oneByAnn()           # 多对一  注解 @One 嵌套 select
├── many2manyByXml(empno)     # 多对多  XML  两次 JOIN + collection
├── many2manyByAnn(empno)     # 多对多  注解 @Many
├── selectSkillsByEmpno(empno)  # 多对多的子查询（中间表）
└── selectListByDeptno(deptno)  # 一对多的子查询

com.chapter05.Chapter05DeptMapper
├── findById(deptno)          # 被 @One 引用
├── one2manyByXml(deptno)     # 一对多  XML  collection 嵌套结果
└── one2manyByAnn(deptno)     # 一对多  注解 @Many

数据表：dept / emp / skill / emp_skill（sql/dept_emp.sql）

    // ==================== XML vs 注解 对比 ====================

    @Test
    public void testComparison() {
        System.out.println("========== XML vs 注解 方式对比 ==========");

        System.out.println("\n--- 一对一 ---");
        Emp empXml = empMapper.one2oneByXml(7369);
        Emp empAnn = empMapper.one2oneByAnn(7369);
        System.out.println("XML: 员工=" + empXml.getEname() + ", 部门=" + empXml.getDept().getDname());
        System.out.println("Ann: 员工=" + empAnn.getEname() + ", 部门=" + empAnn.getDept().getDname());

        System.out.println("\n--- 一对多 ---");
        Dept deptXml = deptMapper.one2manyByXml(20);
        Dept deptAnn = deptMapper.one2manyByAnn(20);
        System.out.println("XML: " + deptXml.getDname() + " 员工数=" + deptXml.getEmps().size());
        System.out.println("Ann: " + deptAnn.getDname() + " 员工数=" + deptAnn.getEmps().size());

        System.out.println("\n--- 多对多 ---");
        Emp empXmlM2M = empMapper.many2manyByXml(7566);
        Emp empAnnM2M = empMapper.many2manyByAnn(7566);
        System.out.println("XML: " + empXmlM2M.getEname() + " 技能数=" +
                (empXmlM2M.getSkills() != null ? empXmlM2M.getSkills().size() : 0));
        System.out.println("Ann: " + empAnnM2M.getEname() + " 技能数=" +
                (empAnnM2M.getSkills() != null ? empAnnM2M.getSkills().size() : 0));
    }

六、注意事项与常见坑

⚠️ 两套实现必须输出一致
  • 同一个业务查询，XML 与注解的结果必须完全相同；不一致说明映射写错了。
  • 重点检查：主键标签、列名别名、select 路径。
✅ 交付自查清单
  • 四种关系的 association / collection 用对了
  • JOIN 中冲突列都起了别名
  • 所有 resultMap 主键都用 <id>
  • @One/@Many 的 select 是接口全限定名
  • 记录了两种方案的 SQL 条数
