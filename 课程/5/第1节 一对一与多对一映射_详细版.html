第05章 第1 一对一与多对一映射 - 详细版

课程代码 1960229 · Java框架技术 · 配套项目：SpringSpringMVCMybatis（Spring 4.3.30.RELEASE + MyBatis 3.5.13）

一、学习目标

  1. 分清单条 JOIN（嵌套结果）与嵌套 select 两种关联实现方式
  2. 会用 <association> 完成「员工 → 部门」的多对一映射
  3. 会用 @One + @Results 完成同样的映射（注解版）
  4. 掌握 JOIN 场景下列名冲突的别名处理（e.deptno AS emp_deptno）

二、核心知识点

1.1 关系判定：emp 有外键，所以是「多对一」

emp 表中有 deptno 外键指向 dept，因此从员工视角看是多对一（多个员工对应一个部门）。Java 侧 Emp 里持有一个 Dept dept 对象，映射标签用 <association>（对应属性是单个对象）。

java
public class Emp implements Serializable {
    private Integer empno;
    private String ename;
    private String job;
    private Date hiredate;
    private Double sal;
    private Integer deptno;   // 外键

    private Dept dept;        // 多对一：一个员工属于一个部门
    private List<Skill> skills;
}

1.2 XML 方案一：嵌套结果（一条 JOIN）

一条 LEFT JOIN 把两张表的列都查出来，resultMap 内部逐列声明。关键点：两张表都有 deptno，必须给 emp 的列起别名 e.deptno AS emp_deptno，否则映射时无法区分。

xml
<resultMap id="empWithDeptMap" type="com.entity.Emp">
    <id property="empno" column="empno"/>
    <result property="ename" column="ename"/>
    <result property="job" column="job"/>
    <result property="sal" column="sal"/>
    <result property="deptno" column="emp_deptno"/>   <!-- 用别名区分！ -->
    <association property="dept" javaType="com.entity.Dept">
        <id property="deptno" column="deptno"/>
        <result property="dname" column="dname"/>
        <result property="loc" column="loc"/>
    </association>
</resultMap>

<select id="one2oneByXml" parameterType="int" resultMap="empWithDeptMap">
    SELECT e.empno, e.ename, e.job, e.sal, e.mgr, e.hiredate, e.comm,
           e.deptno AS emp_deptno,
           d.deptno, d.dname, d.loc
    FROM emp e
    LEFT JOIN dept d ON e.deptno = d.deptno
    WHERE e.empno = #{empno}
</select>

1.3 XML 方案二：嵌套 select（延迟加载）

主查询只查 emp，<association> 上用 select 指定子查询、column 指定把哪一列作为子查询参数。配合 lazyLoadingEnabled=true，不访问 getDept() 就不会发子查询。

xml
<resultMap id="empWithDeptSelectMap" type="com.entity.Emp">
    <id property="empno" column="empno"/>
    <result property="ename" column="ename"/>
    <result property="deptno" column="deptno"/>
    <association property="dept" javaType="com.entity.Dept"
                 select="com.chapter05.Chapter05DeptMapper.findById"
                 column="deptno"/>
</resultMap>

1.4 注解版：@One 嵌套 select

注解版用 @Results 描述映射，用 @One 描述单个关联对象。select 里必须写接口全限定名，即 com.chapter05.Chapter05DeptMapper.findById。

java
@Select("SELECT e.empno, e.ename, e.job, e.sal, e.deptno, " +
        "d.deptno AS d_deptno, d.dname, d.loc " +
        "FROM emp e LEFT JOIN dept d ON e.deptno = d.deptno " +
        "WHERE e.empno = #{empno}")
@Results({
        @Result(property = "empno",  column = "empno"),
        @Result(property = "ename",  column = "ename"),
        @Result(property = "job",    column = "job"),
        @Result(property = "sal",    column = "sal"),
        @Result(property = "deptno", column = "deptno"),
        @Result(property = "dept",   column = "deptno",
                one = @One(select = "com.chapter05.Chapter05DeptMapper.findById"))
})
Emp one2oneByAnn(Integer empno);

1.5 「一对一」与「多对一」在 MyBatis 里写法相同

这两个概念反映的是业务语义（一个员工只有一个部门 / 多个员工共用一个部门），在 MyBatis 的映射层面都表现为「一个对象属性」，都用 <association> / @One。区分它们的意义在于判断「从哪一侧发起查询」。

xml
<!-- 多对一：一次查一批员工，每人带一个部门 -->
<select id="many2oneByXml" resultMap="empWithDeptMap">
    SELECT e.empno, e.ename, e.job, e.sal, e.mgr, e.hiredate, e.comm,
           e.deptno AS emp_deptno,
           d.deptno, d.dname, d.loc
    FROM emp e
    LEFT JOIN dept d ON e.deptno = d.deptno
    ORDER BY e.empno
</select>

三、对照表 / 参数说明

关联映射标签对照

业务关系Java 侧类型XML 标签注解子标签/属性
一对一单个对象<association>@OnejavaType
多对一单个对象<association>@OnejavaType
一对多集合<collection>@ManyofType
多对多集合<collection>@ManyofType + 中间表

两种实现方式对比

维度嵌套结果（JOIN）嵌套 select
SQL 条数1 条1 + N 条
resultMap 写法内联子标签声明列映射select + column
延迟加载不支持支持
列名冲突处理必须起别名不需要
推荐度列表查询首选详情/大对象场景

src/main/java/com/chapter05/Chapter05EmpMapper.java java
package com.chapter05;

import com.entity.Emp;
import com.entity.Skill;
import org.apache.ibatis.annotations.*;

import java.util.List;

public interface Chapter05EmpMapper {

    // ==================== 一对一 ====================

    Emp one2oneByXml(Integer empno);

    @Select("SELECT e.empno, e.ename, e.job, e.sal, e.deptno, " +
            "d.deptno AS d_deptno, d.dname, d.loc " +
            "FROM emp e LEFT JOIN dept d ON e.deptno = d.deptno " +
            "WHERE e.empno = #{empno}")
    @Results({
            @Result(property = "empno", column = "empno"),
            @Result(property = "ename", column = "ename"),
            @Result(property = "job", column = "job"),
            @Result(property = "sal", column = "sal"),
            @Result(property = "deptno", column = "deptno"),
            @Result(property = "dept", column = "deptno",
                    one = @One(select = "com.chapter05.Chapter05DeptMapper.findById"))
    })
    Emp one2oneByAnn(Integer empno);

    // ==================== 多对一 ====================

    List<Emp> many2oneByXml();

    @Select("SELECT e.empno, e.ename, e.job, e.sal, e.deptno, " +
            "d.deptno AS d_deptno, d.dname, d.loc " +
            "FROM emp e LEFT JOIN dept d ON e.deptno = d.deptno")
    @Results({
            @Result(property = "empno", column = "empno"),
            @Result(property = "ename", column = "ename"),
            @Result(property = "job", column = "job"),
            @Result(property = "sal", column = "sal"),
            @Result(property = "deptno", column = "deptno"),
            @Result(property = "dept", column = "deptno",
                    one = @One(select = "com.chapter05.Chapter05DeptMapper.findById"))
    })
    List<Emp> many2oneByAnn();

    // 多对多部分见第3节
    Emp many2manyByXml(Integer empno);
    Emp many2manyByAnn(Integer empno);

    @Select("SELECT s.id, s.name, s.description " +
            "FROM skill s " +
            "INNER JOIN emp_skill es ON s.id = es.skill_id " +
            "WHERE es.empno = #{empno}")
    List<Skill> selectSkillsByEmpno(@Param("empno") Integer empno);

    @Select("SELECT * FROM emp WHERE deptno = #{deptno}")
    List<Emp> selectListByDeptno(@Param("deptno") Integer deptno);
}

六、注意事项与常见坑

⚠️ JOIN 时同名外键列必须起别名
  • emp 与 dept 都有 deptno，若不写 e.deptno AS emp_deptno，resultMap 无法区分两个 deptno，员工自己的部门号会被部门的部门号覆盖。
  • 项目 chapter05 的映射正是靠这个别名才正确。
📌 主键用 <id>，外键关联列用 <result>
  • empno 是 Emp 的主键 → <id>；
  • emp_deptno 只是普通列 → <result>。
  • 关联对象 Dept 内部的 deptno 也是 <id>。
✅ 选方案的经验法则
  • 列表页要展示关联信息 → 嵌套结果（一条 JOIN）。
  • 详情页、关联对象很大且不总访问 → 嵌套 select + 延迟加载。

七、小结

✅ 本节要点
  • 能根据外键位置判定关系类型，并选对 association / collection
  • 会写嵌套结果映射，并知道同名外键列必须起别名
  • 会写嵌套 select 映射（XML 与注解两种）
  • 知道 @One/@Many 的 select 必须写接口全限定名
