二、第1学时：注解开发完整操作

2.1 创建注解方式的 Mapper 接口

操作：创建 UserMapperAnnotation.java 接口，使用注解方式

package com.example.mapper;

import com.example.entity.User;
import org.apache.ibatis.annotations.*;

import java.util.List;
import java.util.Map;

/**
 * 用户 Mapper 接口（注解方式）
 */
public interface UserMapperAnnotation {

    /**
     * 查询所有用户（@Select 注解）
     */
    @Select("SELECT * FROM user")
    List findAll();

    /**
     * 根据 ID 查询用户
     */
    @Select("SELECT * FROM user WHERE id = #{id}")
    User findById(Integer id);

    /**
     * 添加用户（@Insert 注解 + 获取自增主键）
     */
    @Insert("INSERT INTO user(username, password, email) VALUES(#{username}, #{password}, #{email})")
    @Options(useGeneratedKeys = true, keyProperty = "id")
    int addUser(User user);

    /**
     * 更新用户（@Update 注解）
     */
    @Update("UPDATE user SET username=#{username}, email=#{email} WHERE id=#{id}")
    int updateUser(User user);

    /**
     * 删除用户（@Delete 注解）
     */
    @Delete("DELETE FROM user WHERE id = #{id}")
    int deleteUser(Integer id);

    /**
     * 多条件查询（@Param 注解）
     */
    @Select("SELECT * FROM user WHERE username=#{name} AND email=#{email}")
    List findByNameAndEmail(@Param("name") String username, @Param("email") String email);

    /**
     * 模糊查询（${} 用法，注意 SQL 注入风险）
     */
    @Select("SELECT * FROM user WHERE username LIKE '%${username}%'")
    List findByNameLike(@Param("username") String username);

    /**
     * 动态表名查询（${} 正确用法）
     */
    @Select("SELECT * FROM ${tableName}")
    List findAllByTableName(@Param("tableName") String tableName);
}
注意事项：
  • 使用注解方式，不需要创建 UserMapperAnnotation.xml 文件
  • 但需要在 mybatis-config.xml 中注册这个 Mapper 接口

2.2 注册注解方式的 Mapper 接口

操作：在 mybatis-config.xml 中添加 <mapper class="..."/>

<!-- 注册 Mapper（注解方式） -->
<mappers>
    <!-- XML 方式 -->
    <mapper resource="mapper/UserMapper.xml"/>
    
    <!-- 注解方式（使用 class 属性） -->
    <mapper class="com.example.mapper.UserMapperAnnotation"/>
</mappers>

两种注册方式对比：

方式 配置 适用场景
XML 方式 <mapper resource="mapper/XXXMapper.xml"/> SQL 写在 XML 文件中
注解方式 <mapper class="com.example.mapper.XXXMapper"/> SQL 写在注解中

2.3 编写测试类，测试注解方式

操作：创建 UserMapperAnnotationTest.java 测试类

package com.example;

import com.example.entity.User;
import com.example.mapper.UserMapperAnnotation;
import org.apache.ibatis.io.Resources;
import org.apache.ibatis.session.SqlSession;
import org.apache.ibatis.session.SqlSessionFactory;
import org.apache.ibatis.session.SqlSessionFactoryBuilder;
import org.junit.After;
import org.junit.Before;
import org.junit.Test;

import java.io.IOException;
import java.io.InputStream;
import java.util.List;

/**
 * 注解方式 Mapper 测试类
 */
public class UserMapperAnnotationTest {

    private InputStream is;
    private SqlSession session;
    private UserMapperAnnotation userMapper;

    @Before
    public void init() throws IOException {
        is = Resources.getResourceAsStream("mybatis-config.xml");
        SqlSessionFactory factory = new SqlSessionFactoryBuilder().build(is);
        session = factory.openSession(true);
        userMapper = session.getMapper(UserMapperAnnotation.class);
    }

    @After
    public void destroy() throws IOException {
        if (session != null) session.close();
        if (is != null) is.close();
    }

    @Test
    public void testFindAll() {
        List users = userMapper.findAll();
        for (User user : users) {
            System.out.println(user);
        }
        assert users.size() > 0;
    }

    @Test
    public void testFindByNameAndEmail() {
        List users = userMapper.findByNameAndEmail("张三", "zhangsan@qq.com");
        for (User user : users) {
            System.out.println(user);
        }
    }

    @Test
    public void testFindByNameLike() {
        // 注意：这里存在 SQL 注入风险（演示用）
        List users = userMapper.findByNameLike("张");
        for (User user : users) {
            System.out.println(user);
        }
    }
}

三、第2学时：@Param 注解详细操作

3.1 多参数传递问题复现

操作：创建不带 @Param 注解的方法，运行测试，查看报错

// 错误示例：多个参数，没有 @Param 注解
@Select("SELECT * FROM user WHERE username=#{username} AND password=#{password}")
User login(String username, String password);

// 调用时报错：
// Parameter 'username' not found. Available parameters are [arg0, arg1, param1, param2]

3.2 使用 @Param 注解解决问题

操作：添加 @Param 注解，指定参数名

// 正确示例：使用 @Param 注解
@Select("SELECT * FROM user WHERE username=#{username} AND password=#{password}")
User login(@Param("username") String username, @Param("password") String password);

// 调用
User user = userMapper.login("张三", "123456");
System.out.println(user);

3.3 使用 Map 传递多个参数

操作：当参数较多时，使用 Map 集合

// Mapper 接口
@Select("SELECT * FROM user WHERE username=#{username} AND email=#{email} AND password=#{password}")
List findUserByMap(Map map);

// 测试类
@Test
public void testFindUserByMap() {
    Map map = new HashMap<>();
    map.put("username", "张三");
    map.put("email", "zhangsan@qq.com");
    map.put("password", "123456");
    
    List users = userMapper.findUserByMap(map);
    for (User user : users) {
        System.out.println(user);
    }
}

四、第3学时：#{} 和 ${} 对比实验

4.1 #{} 占位符测试（安全）

操作：使用 #{} 进行参数传递，查看日志输出

@Select("SELECT * FROM user WHERE username = #{username}")
User findByUsername(@Param("username") String username);

// 测试
@Test
public void testFindByUsername() {
    User user = userMapper.findByUsername("张三");
    System.out.println(user);
}

// 日志输出：
// ==>  Preparing: SELECT * FROM user WHERE username = ?
// ==> Parameters: 张三(String)
// <==      Total: 1

分析：

  • SQL 语句使用 ? 占位符（PreparedStatement）
  • 参数值通过 Parameters 传入
  • 安全，防 SQL 注入

4.2 ${} 字符串拼接测试（不安全）

操作：使用 ${} 进行参数传递，查看日志输出

@Select("SELECT * FROM user WHERE username = '${username}'")
User findByUsername2(@Param("username") String username);

// 测试
@Test
public void testFindByUsername2() {
    User user = userMapper.findByUsername2("张三");
    System.out.println(user);
}

// 日志输出：
// ==>  Preparing: SELECT * FROM user WHERE username = '张三'
// ==> Parameters:
// <==      Total: 1

分析：

  • SQL 语句直接拼接字符串（Statement）
  • 没有 Parameters 输出（参数直接拼接到 SQL 中）
  • 不安全，易 SQL 注入

4.3 SQL 注入演示

操作：演示 ${} 的 SQL 注入风险

// 使用 ${}（危险）
@Select("SELECT * FROM user WHERE username = '${username}' AND password = '${password}'")
User loginUnsafe(@Param("username") String username, @Param("password") String password);

// 测试 SQL 注入
@Test
public void testSqlInjection() {
    // 正常输入
    User user1 = userMapper.loginUnsafe("张三", "123456");
    System.out.println("正常登录：" + user1);
    
    // SQL 注入攻击
    User user2 = userMapper.loginUnsafe("admin' -- ", "任意密码");
    System.out.println("SQL注入登录：" + user2);
    // 结果：user2 不为 null，登录成功（攻击成功！）
}

// 使用 #{}（安全）
@Select("SELECT * FROM user WHERE username = #{username} AND password = #{password}")
User loginSafe(@Param("username") String username, @Param("password") String password);

// 测试
@Test
public void testSqlInjectionSafe() {
    // SQL 注入攻击（失败）
    User user = userMapper.loginSafe("admin' -- ", "任意密码");
    System.out.println("安全登录：" + user);
    // 结果：user 为 null，登录失败（攻击失败！）
}

五、第4学时：XML 与注解混合开发

5.1 混合开发场景

场景：简单 CRUD 用注解，复杂 SQL 用 XML

操作：在同一个项目中，部分方法用注解，部分方法用 XML

// UserMapperMixed.java（混合开发）
public interface UserMapperMixed {
    
    // 简单查询：使用注解
    @Select("SELECT * FROM user WHERE id = #{id}")
    User findById(Integer id);
    
    // 复杂查询：使用 XML（在 UserMapperMixed.xml 中配置）
    List findByCondition(User user);
}

5.2 注册混合开发的 Mapper

操作：在 mybatis-config.xml 中同时注册接口和 XML

<mappers>
    <!-- 注册 Mapper 接口（注解方式） -->
    <mapper class="com.example.mapper.UserMapperMixed"/>
    
    <!-- 注册 Mapper XML（XML 方式） -->
    <mapper resource="mapper/UserMapperMixed.xml"/>
</mappers>
注意：如果接口和 XML 的 namespace 一致，只需要注册其中一个即可
