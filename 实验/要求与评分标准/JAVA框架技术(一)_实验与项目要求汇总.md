## 四、实验一要求（MyBatis 与 MyBatis-Plus 环境 + CRUD）

业务载体：`ssm_emp.emp` 员工表（建表 SQL 见指导书任务 1.1）。

**任务清单**
1. 环境搭建（2 学时）：Maven 阿里云镜像、Git 初始化与首次 commit、AI 插件安装配置、pom 依赖引入并核对版本统一性
2. MyBatis 基础 CRUD（2 学时）：mybatis-config.xml（驼峰映射 + LOG4J）、实体类、Mapper 接口 + XML 映射（resultMap、useGeneratedKeys 主键回填）、封装 MyBatisUtil 工具类、Log4j 集成、JUnit 测试（**增删改必须 session.commit()**）
3. 动态 SQL（1 学时）：if/where 多条件模糊、set 动态更新、foreach 批量插入/删除、choose 分支；多参数必须 @Param
4. MyBatis-Plus（1 学时）：替换依赖、@TableName/@TableId 注解、BaseMapper 零 SQL CRUD、LambdaQueryWrapper 条件构造、分页插件注册与 selectPage
5. 穿插任务：制造 3 类错误做日志排查演练（占位符大小写、resultMap 列名写错、删除 useGeneratedKeys）；ApiFox 基础练习；按审查清单人工校验 AI 代码（版本兼容、SQL 正确性、#{} vs ${}、映射完整性、代码规范）

**报告重点**：环境搭建截图、SQL 日志截图、JUnit 测试结果截图、≥2 个真实问题及解决过程、AI 应用记录、思考题解答。

**思考题**：#{} 与 ${} 区别；三大核心组件关系与生命周期；N+1 问题；手写 XML vs 条件构造器；AI 代码质量与校验手段。

## 五、实验二要求（SSM 整合 + EMP 员工管理 MIS）

**任务清单**
1. 双师课堂（2 学时）：听课笔记 + 整理**不少于 10 条**「企业开发规范清单」（后续自检依据，随交付物提交）
2. 项目初始化（1 学时）：Maven Web 项目 emp-mis（war 包）、标准分层目录（config/controller/service/mapper/entity/dto/common/interceptor）、统一依赖版本、.gitignore、首次提交
3. SSM 全注解整合（2 学时）：ServletContainersInitConfig（替代 web.xml）、SpringConfig（Druid + SqlSessionFactoryBean + MP 分页插件 + MapperScannerConfigurer + 声明式事务）、SpringMvcConfig（@EnableWebMvc、跨域、LoginInterceptor、静态资源放行）；整合验证（临时 Controller / 临时 Service）
4. 数据库设计 + AI 分层代码生成（1 学时）：emp_name 建索引、字段约束、init.sql 纳入 Git（sql/init.sql）；AI 逐层生成实体/Mapper/Service/Controller 后**逐层人工校验**；统一返回 Result\<T\>（code/message/data）
5. 核心功能（2 学时）：RESTful 接口全套——POST /emps、PUT /emps、DELETE /emps/{id}、DELETE /emps（批量）、GET /emps/{id}、GET /emps（name/gender/dept/page/size 分页多条件）；ApiFox 逐一调试
6. 健壮性与工程化（1 学时）：JSR-303 校验（@Valid + BindingResult）、GlobalExceptionHandler（@RestControllerAdvice 兜底）、登录拦截器（401 JSON）、AOP 请求日志切面；**事务验证**：制造异常观察回滚，并逐项测试三种事务失效场景（异常被 try-catch 吞、this 自调用绕过代理、注解加在 private 方法上）
7. 系统化测试与复盘（1 学时）：ApiFox 用例集（正常/非法参数/异常场景/分页边界）并导出；AI 辅助调试与慢查询优化建议；Git 提交信息规范（feat/fix/refactor 前缀）+ tag v1.0.0

**报告重点**：全流程记录、测试响应截图、事务失效三场景的现象与原因、AI 应用记录。

**思考题**：DispatcherServlet 请求处理流程；父子容器扫描划分；≥3 种事务失效场景及底层原因；拦截器 vs AOP 执行时机；RESTful 语义与统一返回格式价值；AI 辅助模式下的个人工作边界。

## 九、易踩的技术坑（排查分占 20 分，提前规避）

| 现象 | 原因与对策 |
|---|---|
| 分页不生效，返回全量数据 | 未注册 MP 分页插件；用 `MybatisPlusInterceptor.addInnerInterceptor(new PaginationInnerInterceptor())` |
| BindingException: Invalid bound statement | 映射文件未注册、namespace 与接口全限定名不一致、XML 未编译进 target |
| Parameter not found | 多参数未加 @Param |
| 查询字段为 null | 未开驼峰映射或 resultMap 未覆盖全部字段 |
| 依赖冲突 / ClassNotFoundException | MP 与 MyBatis 版本冲突 → 统一由 MP 3.5.3.1 提供 MyBatis 核心 |
| 事务不回滚 | 异常被捕获吞掉、this 自调用、未指定 rollbackFor、注解在 private 方法上 |
| 404 / NoSuchBeanDefinition | 拦截路径或 getServletMappings 配置错；父子容器扫描范围冲突 |
| 中文乱码 / 415 | 连接串加 characterEncoding=utf8（库用 utf8mb4）；请求头 Content-Type 设 application/json |

## 十、指导书示例代码的三处已知瑕疵（复现时须修正，勿照抄）

1. **任务 4.2**：`@TableLogic` 加在业务字段 `status` 上——逻辑删除标记应为独立 `deleted` 字段；照抄会导致 status=0（离职）的记录在 MP 查询中被过滤"消失"。
2. **任务 4.5**：分页插件的 XML `<property name="@...">` 写法不是 MP 3.5.x 正确配置；以实验二注解写法为准。
3. **任务 6.3**：LoginInterceptor 中 JSON 字符串引号未正确转义，需自行修正为 `"{\"code\":401,\"message\":\"未登录\"}"`（内部引号必须 `\"` 转义，否则编译不过）。
